# Visual assets

[Documentation home](../README.md)

- [passageharbor-hero.svg](passageharbor-hero.svg): repository identity and pipeline motif.
- [interface-guide.svg](interface-guide.svg): schematic guide to document controls, an answer, and numbered sources.
- [architecture.svg](architecture.svg): local computation/storage and the Groq generation boundary.

All three are editable native SVGs with accessibility titles/descriptions and no external font/image dependencies or executable scripts. The interface graphic is illustrative and uses synthetic text; it is not a screenshot, live Groq output, or retrieval-quality measurement. Color and labels carry meaning together so boundaries do not depend on color alone.

These assets are covered by the repository's MIT license. Third-party badges in the README are served by GitHub/Shields and are not bundled assets. Mermaid diagrams remain as fenced source in the documentation; see [GitHub's diagram documentation](https://docs.github.com/en/get-started/writing-on-github/working-with-advanced-formatting/creating-diagrams) for rendering support.
