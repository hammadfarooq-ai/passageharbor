# Design archive

[Documentation home](../README.md) · [Current architecture](../architecture.md)

[initial-flow.tldr](initial-flow.tldr) preserves the original editable tldraw design file from the project. It predates the finished application and includes early labels such as Ollama embeddings. It is historical context, not the current architecture or a setup requirement.

The authoritative design is described in the architecture guide and current Python source. The README's SVG identity/interface graphics and the architecture SVG live in [assets](../assets/README.md). Mermaid diagrams are embedded directly in Markdown so contributors can edit and review them as text.
